# Как выполнить дополнительные задания конвертера

Практическое руководство для пяти дополнительных заданий лабораторной работы. Каждый раздел самостоятельный: выбери одно задание и выполняй только его. Код ниже рассчитан на текущую архитектуру проекта:

```text
ConverterScreen → ConverterState → CurrencyRepository → CurrencyApi → ExchangeRate
```

В лабораторной перечислены избранные валюты, история конвертаций, кэш последнего успешного курса, график курса и автоматическое обновление. По требованиям к сдаче нужно выполнить одно дополнительное задание. Остальные можно оставить на потом.

## Перед началом

Сначала сохрани копию проекта или создай ветку Git. Затем выбери один вариант. После каждого изменения запускай приложение и проверяй сценарии именно этого задания.

Основные текущие файлы:

- `lib/state/converter_state.dart` — состояние и действия пользователя.
- `lib/repositories/currency_repository.dart` — получение данных для состояния.
- `lib/services/currency_api.dart` — запросы Frankfurter.
- `lib/models/exchange_rate.dart` — модель одного курса.
- `lib/widgets/converter_screen.dart` — интерфейс.
- `lib/main.dart` — создание объектов и запуск приложения.

В коде будут встречаться уже используемые конструкции:

- `notifyListeners()` сообщает экрану об изменении состояния.
- `ListenableBuilder` перестраивает интерфейс после такого уведомления.
- `Future` и `async/await` нужны для операций, которые завершаются позже: API и сохранение данных.
- После добавления пакета запускай `flutter pub add имя_пакета`, а не вписывай предполагаемую версию вручную. Pub подберёт совместимую версию и обновит lock-файл.

## Вариант 1. Избранные валюты

### Идея

Пользователь может отметить код валюты звёздочкой, увидеть список избранных валют и выбрать одну из них как целевую. Для самого простого выполнения список живёт в памяти до закрытия приложения. В конце этого раздела описан вариант сохранения списка между запусками.

### Какие файлы менять

- `lib/state/converter_state.dart` — добавить список избранного и методы.
- `lib/widgets/converter_screen.dart` — добавить кнопку-звёздочку и список избранных кодов.
- Для сохранения после закрытия приложения дополнительно: `pubspec.yaml` и `ConverterState`.

### Шаг 1. Добавить избранное в состояние

В `ConverterState` рядом с другими полями добавь:

```dart
final List<String> favoriteCurrencies = [];

bool isFavorite(String currency) {
  return favoriteCurrencies.contains(currency);
}

void toggleFavorite(String currency) {
  if (favoriteCurrencies.contains(currency)) {
    favoriteCurrencies.remove(currency);
  } else {
    favoriteCurrencies.add(currency);
  }

  notifyListeners();
}
```

- Список хранит выбранные коды, например `['USD', 'RUB']`.
- `contains` проверяет, есть ли код в списке.
- `toggleFavorite` добавляет валюту, если её ещё нет, или удаляет, если она уже избранная.
- `notifyListeners()` обновляет все слушающие состояние виджеты.

### Шаг 2. Поставить звёздочку рядом с выбором валюты

В `converter_screen.dart` в `Column`, например под `Row` с выпадающими списками, добавь:

```dart
OutlinedButton.icon(
  onPressed: () => state.toggleFavorite(state.toCurrency),
  icon: Icon(
    state.isFavorite(state.toCurrency) ? Icons.star : Icons.star_border,
  ),
  label: const Text('Избранная валюта'),
),
```

Кнопка отмечает выбранную целевую валюту. Иконка меняется в зависимости от того, есть ли код в списке.

### Шаг 3. Показать список избранного

Ниже кнопки вставь:

```dart
Wrap(
  spacing: 8,
  children: state.favoriteCurrencies.map((currency) {
    return ActionChip(
      label: Text(currency),
      onPressed: () => state.setToCurrency(currency),
    );
  }).toList(),
),
```

`Wrap` переносит элементы на следующую строку, если они не помещаются по ширине. `ActionChip` показывает одну избранную валюту; нажатие выбирает её для конвертации.

### Проверка

1. Выбери `RUB` как целевую валюту и нажми кнопку-звёздочку.
2. Проверь, что `RUB` появилась в списке и иконка стала заполненной.
3. Добавь `USD`, затем выбери `RUB` через чип.
4. Сними `RUB` со звёздочки и проверь, что чип исчез.
5. Убедись, что добавление одной валюты несколько раз не создаёт дубликаты.

### Необязательно: сохранить избранное между запусками

Для небольшого списка строк подойдёт пакет `shared_preferences`:

```bash
flutter pub add shared_preferences
```

В `converter_state.dart` добавь импорт и поле:

```dart
import 'package:shared_preferences/shared_preferences.dart';

final preferences = SharedPreferencesAsync();
```

Загрузи и сохрани список:

```dart
Future<void> loadFavorites() async {
  final saved = await preferences.getStringList('favoriteCurrencies');
  favoriteCurrencies
    ..clear()
    ..addAll(saved ?? []);
  notifyListeners();
}

Future<void> saveFavorites() async {
  await preferences.setStringList('favoriteCurrencies', favoriteCurrencies);
}
```

Чтобы сохранить список и только потом уведомить экран, измени метод на асинхронный:

```dart
Future<void> toggleFavorite(String currency) async {
  if (favoriteCurrencies.contains(currency)) {
    favoriteCurrencies.remove(currency);
  } else {
    favoriteCurrencies.add(currency);
  }

  await saveFavorites();
  notifyListeners();
}
```

Загрузка асинхронная, поэтому вызови `loadFavorites()` один раз после создания `ConverterState`, например в `initState()` класса `_MyAppState` в `main.dart`:

```dart
@override
void initState() {
  super.initState();
  converterState.loadFavorites();
}
```

Для такой настройки `_MyAppState` должен хранить один экземпляр `converterState`, как сейчас. Preferences подходят для простых настроек и небольших списков, но не являются базой данных для критически важных данных. Синтаксис `SharedPreferencesAsync` и ограничение назначения пакета описаны в [документации shared_preferences](https://pub.dev/packages/shared_preferences).

## Вариант 2. История конвертаций

### Идея

После каждого успешного расчёта приложение сохраняет запись: сумма, обе валюты, курс, результат и дата. Ошибочные попытки не добавляются. Ниже приведён простой вариант, где история остаётся в памяти до закрытия приложения.

### Какие файлы менять

- Новый файл `lib/models/conversion_record.dart` — структура одной записи.
- `lib/state/converter_state.dart` — список и добавление новой записи.
- `lib/widgets/converter_screen.dart` — отображение списка.

### Шаг 1. Создать модель записи

Создай `lib/models/conversion_record.dart`:

```dart
class ConversionRecord {
  final String fromCurrency;
  final String toCurrency;
  final double amount;
  final double rate;
  final double result;
  final String date;

  ConversionRecord({
    required this.fromCurrency,
    required this.toCurrency,
    required this.amount,
    required this.rate,
    required this.result,
    required this.date,
  });
}
```

У каждой записи свои поля, поэтому историю проще показывать и позже сохранять, чем хранить отдельные списки сумм, валют и дат.

### Шаг 2. Добавить список и запись в `ConverterState`

Импортируй модель и объяви список рядом с остальными полями:

```dart
import '../models/conversion_record.dart';

final List<ConversionRecord> history = [];
```

Внутри `try` метода `convert`, после получения нового курса, используй локальные переменные, чтобы создать запись:

```dart
final newRate = await repository.getRate(fromCurrency, toCurrency);
final converted = amount * newRate.rate;

exchangeRate = newRate;
convertedAmount = converted;

history.insert(
  0,
  ConversionRecord(
    fromCurrency: fromCurrency,
    toCurrency: toCurrency,
    amount: amount,
    rate: newRate.rate,
    result: converted,
    date: newRate.date,
  ),
);
```

`insert(0, ...)` помещает новую конвертацию в начало списка, чтобы сначала показывалась последняя. Добавляй запись только после ответа API: тогда ошибки сети не окажутся в успешной истории.

### Шаг 3. Показать историю на экране

В `converter_screen.dart` под карточкой результата, пока в `Column` главного экрана, можно добавить:

```dart
const SizedBox(height: 24),
const Text('История'),
...state.history.map((record) {
  return ListTile(
    title: Text(
      '${record.amount} ${record.fromCurrency} → '
      '${record.result.toStringAsFixed(2)} ${record.toCurrency}',
    ),
    subtitle: Text('Курс: ${record.rate} · Дата: ${record.date}'),
  );
}),
```

Оператор `...` вставляет элементы списка внутрь списка `children` виджета `Column`. Для совсем длинной истории добавь ограничение, например сохраняй только 20 записей.

### Проверка

1. Сделай одну успешную конвертацию — запись должна появиться первой.
2. Сделай конвертацию другой валютной пары — старая запись остаётся ниже.
3. Отключи интернет и попробуй конвертировать — неуспешная попытка не добавляется.
4. Поменяй валюты местами и проверь порядок валют в новой записи.
5. Закрой и открой приложение: в этом простом варианте список очистится. Если по требованиям преподавателя история должна сохраняться между запусками, см. следующий подраздел.

### Необязательно: сохранить историю между запусками

Нужно добавить в `ConversionRecord` методы `toJson()` и `fromJson()`, затем хранить список как JSON-строку через `SharedPreferencesAsync`. Схема такая:

```dart
final jsonText = jsonEncode(history.map((item) => item.toJson()).toList());
await preferences.setString('conversionHistory', jsonText);
```

При чтении нужно выполнить обратные шаги: `jsonDecode`, убедиться, что результат — список, превратить каждый элемент в `Map<String, dynamic>` и создать `ConversionRecord.fromJson(...)`. Сохранение истории — необязательное усложнение; начни с работающего списка в памяти.

## Вариант 3. Кэш последнего успешного курса

### Идея

Репозиторий запоминает успешно загруженный курс для каждой пары валют. Если следующий запрос не проходит, он возвращает сохранённый курс. Для начала кэш будет храниться в памяти, то есть пропадёт после закрытия приложения.

### Какой файл менять

- `lib/repositories/currency_repository.dart`.

### Шаг 1. Добавить память кэша

В `CurrencyRepository` добавь:

```dart
final Map<String, ExchangeRate> cache = {};
```

Ключом будет строка пары, например `EUR-RUB`, а значением — последний успешный объект `ExchangeRate`.

### Шаг 2. Изменить `getRate`

Замени текущую передачу запроса на:

```dart
Future<ExchangeRate> getRate(String from, String to) async {
  final key = '$from-$to';
  final savedRate = cache[key];

  try {
    final newRate = await api.getRate(from, to);
    cache[key] = newRate;
    return newRate;
  } catch (_) {
    if (savedRate != null) {
      return savedRate;
    }

    rethrow;
  }
}
```

- Сначала запоминаем кэшированный курс, если он есть.
- Пытаемся запросить свежий курс.
- Только при успехе обновляем кэш.
- При ошибке возвращаем сохранённый курс этой же пары.
- Если кэша нет, `rethrow` передаёт исходную ошибку обратно в `ConverterState`.

Так новый успешный ответ всегда обновляет кэш, а ошибка не затирает хорошие сохранённые данные.

### Шаг 3. Объяснить пользователю, что курс может быть старым

У модели уже есть дата курса. При возврате из кэша эта дата останется старой — это полезный признак. Не показывай кэшированный курс так, будто он только что обновился. Если понадобится отдельная пометка «данные из кэша», добавь в модель/результат признак `isCached` или возвращай из репозитория отдельный объект с курсом и признаком источника.

### Проверка

1. При включённом интернете запроси `EUR → RUB` — ответ должен сохраниться в `cache`.
2. Отключи интернет и повтори тот же запрос — должен вернуться сохранённый курс.
3. Отключи интернет и запроси новую пару, которой ещё нет в кэше — должна показаться ошибка.
4. Включи интернет и повтори запрос — кэш должен обновиться.
5. Закрой приложение и проверь поведение: в этой версии кэш пустой после перезапуска.

### Если кэш должен переживать перезапуск

Сохраняй данные в Preferences или в файл. Для Preferences курс и дату можно кодировать в JSON-строку и сохранять под ключом пары. При старте загрузи их в `cache`. Не сохраняй результат конвертации вместо курса: один сохранённый курс применим к разным суммам.

## Вариант 4. График курса

### Идея

Для графика нужна не одна сегодняшняя ставка, а список ставок по датам. В Frankfurter v2 для временного ряда используется `/v2/rates` с параметрами `base`, `quotes`, `from` и `to`. Ответ — список объектов с датой и курсом. [Документация Frankfurter](https://frankfurter.dev/)

### Какие файлы менять

- `lib/services/currency_api.dart` — новый метод, который получает ряд ставок.
- `lib/repositories/currency_repository.dart` — передаёт запрос истории.
- `lib/state/converter_state.dart` — хранит точки графика и загружает их.
- `lib/widgets/converter_screen.dart` или новый `lib/widgets/currency_chart.dart` — рисует линию.
- `pubspec.yaml` — добавить библиотеку `fl_chart`.

### Шаг 1. Добавить библиотеку графиков

```bash
flutter pub add fl_chart
```

`fl_chart` поддерживает линейные графики и точки `FlSpot(x, y)`. Синтаксис может изменяться вместе с пакетами — смотри текущие примеры и API на [странице fl_chart](https://pub.dev/packages/fl_chart) и в [описании линейного графика](https://github.com/imaNNeo/fl_chart/blob/main/repo_files/documentations/line_chart.md).

### Шаг 2. Добавить запрос временного ряда в `CurrencyApi`

Импорт `dart:convert` и модель уже есть. Добавь в `CurrencyApi` новый метод:

```dart
Future<List<ExchangeRate>> getHistory(
  String from,
  String to,
  String startDate,
  String endDate,
) async {
  final url = Uri.https(
    'api.frankfurter.dev',
    '/v2/rates',
    {
      'base': from.toLowerCase(),
      'quotes': to.toLowerCase(),
      'from': startDate,
      'to': endDate,
    },
  );

  final response = await http.get(url).timeout(const Duration(seconds: 10));

  if (response.statusCode != 200) {
    throw Exception('Не удалось получить историю курса');
  }

  final json = jsonDecode(response.body) as List<dynamic>;
  return json.map((item) {
    return ExchangeRate.fromJson(item as Map<String, dynamic>);
  }).toList();
}
```

`Uri.https` аккуратно собирает адрес с параметрами запроса. `List<dynamic>` — список записей JSON. Каждая запись имеет те же поля `date` и `rate`, которые уже читает `ExchangeRate.fromJson`.

### Шаг 3. Передать запрос через репозиторий

В `CurrencyRepository` добавь метод:

```dart
Future<List<ExchangeRate>> getHistory(
  String from,
  String to,
  String startDate,
  String endDate,
) {
  return api.getHistory(from, to, startDate, endDate);
}
```

Теперь `ConverterState` по-прежнему не зависит от HTTP-деталей.

### Шаг 4. Загружать точки в состоянии

В `ConverterState` добавь поля:

```dart
List<ExchangeRate> chartRates = [];
bool isChartLoading = false;
String? chartError;
```

Добавь метод загрузки примерно за последний месяц:

```dart
Future<void> loadChart() async {
  isChartLoading = true;
  chartError = null;
  notifyListeners();

  final today = DateTime.now();
  final monthAgo = today.subtract(const Duration(days: 30));
  final endDate = today.toIso8601String().substring(0, 10);
  final startDate = monthAgo.toIso8601String().substring(0, 10);

  try {
    chartRates = await repository.getHistory(
      fromCurrency,
      toCurrency,
      startDate,
      endDate,
    );
  } catch (_) {
    chartError = 'Не удалось загрузить историю курса';
  }

  isChartLoading = false;
  notifyListeners();
}
```

### Шаг 5. Нарисовать линию

Импортируй пакет в виджет графика:

```dart
import 'package:fl_chart/fl_chart.dart';
```

Минимальный виджет графика:

```dart
Widget buildRateChart(List<ExchangeRate> rates) {
  if (rates.length < 2) {
    return const Text('Недостаточно данных для графика');
  }

  final spots = List.generate(rates.length, (index) {
    return FlSpot(index.toDouble(), rates[index].rate);
  });

  return SizedBox(
    height: 240,
    child: LineChart(
      LineChartData(
        lineBarsData: [
          LineChartBarData(
            spots: spots,
            isCurved: true,
            color: const Color(0xFF168A70),
          ),
        ],
      ),
    ),
  );
}
```

Здесь X — порядковый номер точки, Y — значение курса. Такой первый вариант не подписывает каждую дату на оси X; даты можно показать отдельными подписями под графиком. API возвращает только даты, для которых есть наблюдения, поэтому число точек может быть меньше 30.

Добавь в `ConverterScreen` кнопку загрузки и сам график в `Column`:

```dart
FilledButton(
  onPressed: state.isChartLoading ? null : state.loadChart,
  child: const Text('Показать график за месяц'),
),
if (state.isChartLoading) const CircularProgressIndicator(),
if (state.chartError != null) Text(state.chartError!),
if (state.chartRates.isNotEmpty) buildRateChart(state.chartRates),
```

Если код графика вынесен в `currency_chart.dart`, передай ему `state.chartRates` параметром. Так виджет отвечает за рисование, а состояние — за загрузку.

### Проверка

1. Выбери пару валют, для которой Frankfurter публикует историю.
2. Запроси период примерно в месяц.
3. Проверь загрузку, ошибку без сети и отсутствие точек.
4. Проверь, что график содержит более одной точки и значения соответствуют выбранной паре.
5. Поменяй валюты и загрузи график снова.

## Вариант 5. Автоматическое обновление курса

### Идея

После включения режима приложение через заданный интервал повторяет последнюю конвертацию: использует последнюю введённую сумму и текущую пару валют. Для таймера используется встроенный `Timer` из `dart:async`; дополнительный пакет не нужен.

Frankfurter публикует справочные курсы ежедневно, а не каждую секунду. Поэтому для обычной работы разумен большой интервал, например 24 часа. Для демонстрации можно временно поставить 30 секунд, убедиться, что запрос повторяется, и затем вернуть нормальный интервал. Источник указывает на ежедневное обновление: [Frankfurter](https://frankfurter.dev/).

### Какие файлы менять

- `lib/state/converter_state.dart` — сохранить последнюю сумму, запустить/остановить таймер и обязательно отменить его при очистке состояния.
- `lib/widgets/converter_screen.dart` — добавить переключатель автоматического режима.
- `lib/main.dart` менять не нужно: состояние приложения уже освобождается через `dispose()`.

### Шаг 1. Добавить поля и импорт в `ConverterState`

В начало файла:

```dart
import 'dart:async';
```

В класс:

```dart
Timer? refreshTimer;
String? lastAmountText;
bool autoRefreshEnabled = false;
```

`Timer?` может быть создан или равняться `null`. `lastAmountText` нужен, чтобы повторить тот же расчёт.

### Шаг 2. Запоминать сумму

В `convert`, сразу после проверок на `null` и отрицательное значение, запиши:

```dart
lastAmountText = amountText;
```

Так автоматический режим будет обновлять последнюю корректно отправленную сумму. Если пользователь поменял текст, но не нажал конвертацию, таймер продолжит использовать последний расчёт.

### Шаг 3. Добавить включение и выключение

В `ConverterState` добавь:

```dart
void setAutoRefresh(bool enabled) {
  refreshTimer?.cancel();
  autoRefreshEnabled = enabled;

  if (enabled && lastAmountText != null) {
    convert(lastAmountText!);

    refreshTimer = Timer.periodic(const Duration(hours: 24), (_) {
      if (!isLoading && lastAmountText != null) {
        convert(lastAmountText!);
      }
    });
  }

  notifyListeners();
}
```

- Сначала старый таймер отменяется, чтобы не запустить два одновременно.
- При включении сразу выполняется одно обновление, если уже есть последняя сумма.
- `Timer.periodic` запускает повторную функцию каждые 24 часа.
- Проверка `!isLoading` не даёт запустить второй запрос, пока предыдущий ещё выполняется.
- При выключении новый таймер не создаётся.

### Шаг 4. Отменить таймер при закрытии состояния

Добавь в `ConverterState`:

```dart
@override
void dispose() {
  refreshTimer?.cancel();
  super.dispose();
}
```

Если не отменить периодический таймер, он может продолжать запускаться после закрытия экрана/состояния.

### Шаг 5. Добавить переключатель

В `ConverterScreen` вставь в `Column`:

```dart
SwitchListTile(
  title: const Text('Обновлять автоматически'),
  value: state.autoRefreshEnabled,
  onChanged: state.setAutoRefresh,
),
```

Переключатель отображает значение из состояния и при изменении вызывает `setAutoRefresh`.

Для простоты можно сделать переключатель доступным только после первой попытки конвертации, когда `lastAmountText` уже записан. Например, задай `onChanged` равным `null`, пока `state.lastAmountText == null`. Иначе пользователь сможет включить режим до появления суммы, а начать автоматически обновлять будет нечего.

### Проверка

1. Выполни успешную конвертацию, чтобы состояние запомнило сумму.
2. Включи автоматическое обновление и проверь, что сразу выполняется новый запрос.
3. Для демонстрации временно замени `Duration(hours: 24)` на `Duration(seconds: 30)`.
4. Проверь, что кнопки/выбор валют не создают параллельные запросы, пока `isLoading` равен `true`.
5. Выключи режим и проверь, что повторные запросы прекращаются.
6. Верни разумный интервал: Frankfurter обновляет справочные курсы ежедневно, поэтому короткий таймер чаще будет получать ту же дату и ставку.

`Timer.periodic` работает, пока процесс приложения выполняется. Это учебное обновление на переднем плане, а не системная фоновая задача, которая гарантированно сработает, когда Android/iOS усыпили приложение.

## Что выбрать для лабораторной

| Задание | Сложность | Основной файл | Что демонстрировать |
|---|---:|---|---|
| Избранные валюты | Низкая | `converter_state.dart`, `converter_screen.dart` | Добавление, отображение, выбор и удаление избранной валюты. |
| История конвертаций | Низкая–средняя | Новая модель, `converter_state.dart`, экран | Новая запись после успеха, последние операции сверху. |
| Кэш курса | Низкая–средняя | `currency_repository.dart` | После успешного запроса повторить расчёт без интернета и получить старый сохранённый курс. |
| Автообновление | Средняя | `converter_state.dart`, экран | Включить таймер, увидеть повторный запрос, выключить. |
| График | Средняя–высокая | API, репозиторий, состояние, виджет, зависимость | Показать временной ряд и обработать пустые/ошибочные данные. |

Если нужно самое понятное задание для самостоятельного выполнения, начни с избранного или истории. Кэш тоже небольшой, но важно объяснить, где он хранится и насколько старым может быть курс. График требует нового API-метода и сторонней библиотеки.
